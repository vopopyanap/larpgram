# ⚡ Larpgram iOS Client (Visual Spoofing Mod)

Кастомный твик/мод для официального Telegram iOS с визуальным оверлеем для профиля.

### 🌟 Возможности:
* **Кастомный номер телефона:** отображение любого номера (включая анонимные номера Telegram `+888`) вместо реального.
* **Telegram NFT Gifts:** визуальное добавление любых редких подарков и NFT прямо в профиль.
* **Fragment NFT Usernames:** отображение дополнительных коллекционных юзернеймов в списке профиля.
* **Нативное меню «⚡ Larpgram»:** доступ прямо из стандартных Настроек Telegram.

### 🚀 Как получить готовый .IPA за 2 минуты:

1. **Создай репозиторий на GitHub** (можно публичный или приватный).
2. **Запушь этот проект в репозиторий:**
   ```bash
   git init
   git add .
   git commit -m "Init Larpgram"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/larpgram.git
   git push -u origin main
   ```
3. Перейди во вкладку **Actions** в твоём репозитории на GitHub:
   * Запустится автоматический воркфлоу сборки на сервере macOS (`macos-14`).
   * Через 3-5 минут в разделе **Releases** (или **Artifacts**) появится готовый файл **`Larpgram-Telegram.ipa`**.
4. Скачай его и установи на iPhone через **Sideloadly**, **AltStore**, **Scarlet** или **TrollStore**.
